# 自我导向学习辅助器 v1.2.0

**资源不再是单独的一页：路径落盘后，每个节点会自动配上 1–2 条可点的资源。**

## 这一版新增

- **资源随路径自动补齐**：确认路径后自动为阶段里的每个节点检索，直接写入，不需要再回资源页勾选；
- **实时进度**：显示「正在为第 N/M 个节点找资源」，单节点失败可重试，整条路径可「重新补齐」；
- **没有 Tavily 也不空白**：生成 B 站 / YouTube / Bing / MDN 搜索页链接，标记「未验证」；
  配置 Tavily 后「重新补齐」会替换成真实资源；
- **共享 URL**：同一个好资源可以挂在多个节点下，资源库只保留一个 Markdown 文件；
- **资源页改版**：总览、已验证/未验证筛选、删除；手动检索去掉「最多 5 个节点」限制；
- **路径页按节点分组**：每个知识点下面直接列出它的资源，未验证的带徽标。

## 升级说明

- 旧路径不会自动跑资源；打开路径页点「重新补齐资源」即可；
- 旧资源的 `node` 字段仍然兼容；新写入会补上 `nodes` 数组；
- 已存在的资源不会重复创建，同一 URL 只会追加节点关联。

## 已知限制

- 未签名：Windows SmartScreen 点「仍要运行」，macOS 右键 → 打开；
- macOS 未签名时自动更新不可用；
- macOS 只提供 Apple Silicon（arm64）；
- 没有 Tavily 时只能提供搜索页链接，不是具体文章；
- 搜索质量取决于 Tavily 与模型判定，冷门节点可能没有资源。
