# 自我导向学习辅助器 v1.1.1

**修复版：AI 生成知识地图后可以正常落盘了。**

## 本版修复

- 修复：AI 生成地图后点「确认落盘」报 400 的问题。
  原因是候选边在接口里还是内部字段 `fromTempId` / `toTempId`，提交校验要求 `from` / `to`；
  现在生成 20–30 个节点 + 关系边都能正常写入，并补了回归测试。

## 这一版有什么

- Windows 一键安装 / 免安装单文件、macOS（Apple Silicon）dmg/zip、Linux AppImage/zip；
- 数据留在本机：安装版在系统用户目录，便携版在程序旁 `data/vault`；
- API Key 用系统密钥链 `safeStorage` 加密，旧明文自动迁移；
- 原生菜单：打开数据目录、导入 zip、导出 zip、检查更新、使用说明；
- 自动更新：GitHub 为主源，Gitee 为备用源；
- 学习闭环：目标 → 知识地图（蛛网 + 关系边）→ 路径 → 资源 → 验收 → 复盘 → 质量。

## 第一次使用

1. 打开后按欢迎弹窗操作：建目标 → 配 API Key（右上角钥匙）；
2. DeepSeek 必填（生成地图/路径/题目），Tavily 可选（联网找资源）；
3. 去「地图」点「AI 自动生成知识地图」，确认候选后落盘。

没有 Key 也能建目标、看示例库、导入导出。

## 数据与备份

| 形态                            | 数据位置                                                        |
| ------------------------------- | --------------------------------------------------------------- |
| Windows 安装版 / macOS          | 系统用户目录（Windows 为 `%APPDATA%/自我导向学习辅助器/vault`） |
| Windows 便携版 / Linux AppImage | 程序旁 `data/vault`                                             |

「质量」页可导出整库 zip；换机器导入即可。

## 已知限制

- Windows 未签名（SmartScreen 点「更多信息 → 仍要运行」）；macOS 未公证（右键 → 打开）；
- macOS 未签名时自动更新不可用，只提示手动下载；
- macOS 首期只提供 Apple Silicon（arm64）；
- 暂不支持 Windows ARM64。
