# 自我导向学习辅助器 v1.1.0

**第一个桌面版：不用装 Node、不用 Docker，下载后双击就能用。**

你给出一句可判定的目标，它在本地网页里生成知识地图、学习路径、资源、验收题与复盘；
数据始终是你电脑上的 Markdown 文件夹，不注册、不上传。

## 这一版有什么

- **三平台桌面端**：Windows 安装包 / 单文件便携版、macOS dmg、Linux AppImage；
- **数据留在本机**：安装版在系统用户目录，便携版在程序旁的 `data/vault`；
- **API Key 加密**：桌面版用系统密钥链（safeStorage）保存，旧版明文文件会自动迁移；
- **原生菜单**：打开数据目录、导入 zip、导出 zip、检查更新、使用说明；
- **自动更新**：GitHub Releases 为主源，Gitee Releases 为备用源；
- **完整学习闭环**：目标 → 知识地图（蛛网 / 关系边）→ 路径 → 资源 → 验收 → 复盘 → 质量面板；
- **AI 自建地图**：不给材料也能生成 20–30 个知识点；也可以从「导入材料生成」进入独立页。

## 第一次使用

1. 打开后会看到欢迎弹窗：三步说明、Key 配置指引、反馈微信；
2. 在「目标」写下一个想学的东西 + 一句可判定的成功判据；
3. 右上角钥匙图标 →「API Key」：DeepSeek 必填（生成地图/路径/题目）；Tavily 可选（联网找资源）；
4. 去「地图」点「AI 自动生成知识地图」，或在「路径」生成学习路径。

没有 Key 也能建目标、看示例库、导入导出。

## 数据与备份

| 形态                            | 数据位置                                                        |
| ------------------------------- | --------------------------------------------------------------- |
| Windows 安装版 / macOS          | 系统用户目录（Windows 为 `%APPDATA%/自我导向学习辅助器/vault`） |
| Windows 便携版 / Linux AppImage | 程序旁 `data/vault`                                             |

「质量」页可导出整库 zip；换机器时导入即可。索引文件是派生物，删掉会自动重建。

## 已知限制

- Windows 未签名（SmartScreen 提示）、macOS 未公证（需右键打开）；
- macOS 未签名时**自动更新不可用**，检测到新版本只会提示手动下载；
- 暂不支持 Windows ARM64；macOS 首期只出 Apple Silicon（arm64），Intel Mac 暂未提供；
- Gitee 镜像的更新可能比 GitHub 晚几分钟；
- 便携版首次启动需要解压，会比安装版慢几秒。
