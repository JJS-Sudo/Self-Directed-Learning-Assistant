# 自我导向学习辅助器 v1.3.0

**目标终于可以改、可以删了：改名会同步文件与分区，删除会进回收站，误删可恢复。**

## 这一版新增

- **编辑目标**：卡片「⋯」→ 编辑，可改标题、成功判据、类型、期限、状态；
- **改名同步**：目标文件与 `20-学习项目/<id> <标题>/` 分区目录一起改名，id 与节点/路径/资源关联不变；
- **四种状态**：在用 / 暂停 / 已完成 / 已归档；归档只隐藏，不移动文件，可随时改回；
- **软删除回收站**：删除时目标、分区（节点/路径/验收/复盘）与**独占资源**进入 `99-回收站`；
- **共享资源保护**：被其他目标使用的资源只解除本目标节点关联，文件保留；
- **恢复 / 彻底删除**：回收站列表可恢复，也可二次确认后彻底删除；
- **修改时间**：目标写入 `updated_at`；列表可显示最近更新。

## 升级说明

- 旧目标没有 `updated_at` 时按 `created_at` 读取，不要求迁移；
- 删除是软删除，文件进入 `99-回收站`，不会立即丢失；
- 改名会移动目标文件与分区目录，但 id 不变，地图/路径/资源关联不受影响；
- 归档不是删除，文件仍在原位。

## 已知限制

- 删除/恢复是跨目录移动，不是数据库事务；极端中断可能留下半移动（先写 manifest、失败会回滚）；
- 回收站不会自动过期，需要手动彻底删除；
- 不做批量编辑/删除；
- 未签名：Windows SmartScreen 点「仍要运行」，macOS 右键 → 打开；
- macOS 只提供 Apple Silicon（arm64）。
