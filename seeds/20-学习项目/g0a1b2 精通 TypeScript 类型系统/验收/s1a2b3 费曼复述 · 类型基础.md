# 费曼复述 · 类型基础

<!-- sdl:begin -->
用大白话讲一遍：类型就是「给值的形状立规矩」。`string` 是「只准放字符串」，
`{ name: string }` 是「必须有一个 name，而且它是字符串」。类型检查发生在编译期，
所以写错的地方在跑之前就被拦下来了 —— 这也是它和运行时报错最本质的差别。
