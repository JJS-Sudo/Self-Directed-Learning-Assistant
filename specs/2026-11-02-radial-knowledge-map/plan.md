## 实施记录（2026-11-02）

T1–T6 完成，T7 部分完成（浏览器验证了渲染，编辑交互靠 API/单测）。用例从 440 增至 **460**。

| 项       | 结果                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------- |
| 关系模型 | `links: [{to,type}]`，`parent` 同步 `upId`；旧文件由 `upId` 合成；并列/相关双向去重；悬空边忽略         |
| 节点编辑 | PATCH 标题（同步改名）、序号、掌握度；新增节点；删除节点级联清边并返回路径/题目引用                     |
| API      | GET map（goal/nodes/layout/warnings）、节点 CRUD、links POST/DELETE、layout GET/PUT                     |
| 生成     | 提示词输出 `nodes + edges(parent/sibling/related)`；旧 `parent_temp_id` 仍兼容；parent 冲突降级 related |
| 布局     | `d3-force` 纯函数，固定种子；`知识网/布局.json` 持久化，拖拽后 PUT                                      |
| 页面     | 目标卡居中、知识点单色卡片、边标签、详情抽屉、连线模式、刷新布局                                        |

实测（临时库 `%TEMP%\sdl-radial-smoke`，真实目标 `6k74zg` 的副本）：

- API：66 个节点、58 条 parent 边、无预存布局；
- 页面：目标卡「52天速成通过四级」居中、66 张卡片、58 条边全部渲染，标签均为「上级」；
- 真实库 `git status` 零改动。

与计划的偏差：

1. **React Flow 的 edge 层不渲染**：props 里 58 条边、节点 id 全部匹配，但 store 里为 0（v12 下没找到稳定原因）。
   改为**在视口上自绘 SVG 边层**（`useViewport` + 曲线 + 文字标签 + 箭头），点击边仍可选中删除。
2. **旧数据只有 parent 边**：真实目标 58 条全是 parent，没有 sibling/related；后两类由 API/单测覆盖，
   页面上的连线按钮已实现但未逐一点击验证。
3. **拖动保存与删除确认未在浏览器逐项操作**：逻辑走 API 与组件代码，单测覆盖了后端；这部分留给人工复核。

未完成：浏览器里逐项点过「连线 / 删除边 / 拖动后刷新 / 删除节点」并截图。
