## 实施记录（2026-11-01）

T1–T6 完成；T7 除「真 key 重生成」外完成（环境里没有模型 key）。用例从 404 增至 **428**。

| 项       | 结果                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| 运行记录 | `.sdl-runs.json` 追加/读取；损坏时 `.bak` 并降级为空；`costOf` 用真实 usage × 价格表         |
| 面板     | 四类警告归类 + 最近 20 条失败 + 最近 50 条 runs + 预算超支；`GET /quality`                   |
| 预算     | `POST /budget` 写/清 `budget_cny`；超预算 `over: true`，**不阻止生成**                       |
| 重生成   | 只对勾选节点（1–10）发一次请求；请求里不含未勾选节点；结果不写库，确认后走 `map/commit` 追加 |
| 导出     | JSZip；默认排除索引/运行记录/obsidian/canvas；`canvas=1` 才带                                |
| 导入     | 原始 zip；已存在跳过、派生忽略、失败逐条报告；导入后重建索引                                 |
| 页面     | 第七区「质量」：警告分组、失败、费用、预算、重生成、导出/导入                                |

实测证据（临时库 `%TEMP%\sdl-import-demo`，真实运行库只读复制）：

- 真实运行库导出 zip **463KB**；导入空库 → **402 个文件、2 个跳过（`.sdl-vault` 等已存在）、0 失败**；
- `GET /api/goals` 读回 **5 个目标**（与源库一致）；
- `eps3a5` 的质量面板：**1 条地图警告**（叶子未被路径覆盖），页面按「地图」分组显示；
- 往返导出 416KB，再次导入 → **392 条全部 skipped（已存在）**，无覆盖；
- 页面 `/quality`：导航 7 项、警告、费用与两个导出入口都可见；
- 真实运行库：`git status` **0 个文件被改动**。

与计划的偏差：

1. **导入接口改为原始 zip 字节**（`content-type: application/zip`），不是 multipart；页面用
   `File.arrayBuffer()` 直接 POST，少一层表单解析。
2. **zip slip 的实测结果与预期不同**：JSZip 在 `loadAsync` 时会把 `../evil.md` 规范化为 `evil.md`，
   所以「越界」在库层面已被消解；我们仍保留绝对路径/盘符的拒绝（`C:/evil.md` → 400）。
3. **重生成的父节点只能从选中节点里选**：原计划允许引用任意已有节点，但那会把未勾选节点写进请求，
   与门禁 G3 冲突；现在父引用越界会被丢弃并警告。
4. **`4xx` 语义**：不存在的节点/段沿用 404；节点不在目标内是 400。

未完成：**真 key 的子图重生成冒烟**（`DEEPSEEK_API_KEY` 未配置）；其余门禁都有证据。
