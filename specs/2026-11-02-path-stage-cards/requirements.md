## 3. 决策

| #   | 决策                                                               | 理由                         |
| --- | ------------------------------------------------------------------ | ---------------------------- |
| D1  | 布局：**三列网格，每阶段一行**                                     | 与截图一致，三块关系一眼可见 |
| D2  | 阶段卡**全含**：序号/阶段名、估时、产物、节点数、资源              | 访谈选择                     |
| D3  | 资源**按阶段节点自动关联**（`stage.nodeIds`），不新增手选字段      | 现有数据可直接用             |
| D4  | 排序沿用 `rankResources` 的推荐分，同级按 `level`（入门→进阶）     | 与资源页一致，不另造规则     |
| D5  | 新增 `platform` / `price` 字段；缺失时展示「平台未知」「价格未知」 | 截图的信息密度需要结构化字段 |
| D6  | 资源链接一律 `target="_blank" rel="noreferrer"`                    | 不丢当前知识网上下文         |
| D7  | 题目只读列出，点击跳 `/assess?goal=<id>&stage=<id>`                | 保持路径页轻                 |
| D8  | 无资源/无题目显示空态，不隐藏单元格                                | 三列对齐                     |

### 3.1 数据与契约

资源 frontmatter 新字段（都可选）：

```yaml
platform: B站 # B站 / 慕课 / YouTube / 文档 / 书 / 其他
price: 免费 # 免费 / 付费 / 未知
```

- `createResource` 与资源检索生成器接受这两个字段；
- 旧资源读取时 `platform`/`price` 缺失 → `undefined`，页面用「平台未知」「价格未知」占位；
- 排序不因新字段改变（仍按 `rank` 分 + level）。

路径视图 DTO 扩展（`GET /api/goals/:id/path`）：

```ts
{
  stages: {
    id, title, estimate, deliverable?, order, status,
    nodeIds: string[],
    checks: string[],
    questions: { id, title, stem }[],
    resources: {
      id, title, url?, platform?, price?, durationMin?, level, media, rankReason
    }[]
  }[]
}
```

- `questions`：按 `questionIds` 从题目库取；缺失的 id 忽略并计数；
- `resources`：`listResources(root, { nodeIds })` 后 `applyRanking` 排序；
- 不新增写接口。

### 3.2 视觉

- 三列底色：阶段 `#f7f5ef`、检验信号 `#fbf7ea`、验收题目 `#fdf1e8`；细描边、圆角 8px；
- 资源行：`B站 · 免费`（弱色）+ 标题（主色、下划线 hover）+ 时长/理由（小字）；
- 行间箭头用 CSS 伪元素或 SVG，不依赖 canvas；
- 宽屏三列等宽；`< 900px` 时三列上下堆叠，箭头隐藏。

## 5. 风险

| 风险                                               | 缓解                                   |
| -------------------------------------------------- | -------------------------------------- |
| 旧资源没有 platform/price，看起来残缺              | 占位文案 + 后续生成/检索逐步补齐       |
| 资源按节点关联，一个节点资源可能很多，阶段卡被撑长 | 全部展示，不折叠、不限条数             |
| 题目 id 悬空（题被删）                             | 忽略并计数，不显示破链接               |
| 阶段多时页面很长                                   | 保持顺序；后续可加锚点目录（不在本期） |
