## 2. 验收场景

### V1 · 结构

1. 打开 `/path`，选一个有 3+ 阶段的目标；
2. 每行三块，箭头从阶段指向信号、信号指向题目；
3. 阶段卡里能看到资源行。

### V2 · 资源链接

1. 找一个有 url 的资源，点击 → 新标签打开；
2. 无 url 的资源显示为纯文本，不可点；
3. 缺 platform/price → 「平台未知 · 价格未知」。

### V3 · 题目

1. 某阶段 `questionIds` 有 2 条 → 题目列显示 2 条；
2. 点击一条 → `/assess?goal=…&stage=…`；
3. 把某道题的 id 从阶段里删掉 → 不显示破链接。

### V4 · 空态与窄屏

1. 新建一个没有资源的阶段 → 「本段暂无资源」；
2. 缩到手机宽度 → 三列上下堆叠，箭头隐藏。

---

## 3. 不通过的样子

- 仍是纵向列表，或三块不分列。
- 资源链接打不开 / 不是 `<a>` / 同标签页跳走。
- 阶段卡里看不到资源，或资源不分阶段全堆在一起。
- 题目列显示的是全部题目，而不是本阶段的 `questionIds`。
- 旧资源显示成空白而不是占位文案。
- 为了展示字段而批量改写真实库里的资源文件。

---

## 4. 评审者 5 分钟检查单

1. 三列排对了吗？行间箭头在吗？
2. 阶段卡里有资源链接吗？点击新标签打开吗？
3. 题目数是本阶段的吗？点进去带 stage 参数吗？
4. 旧资源缺字段时显示占位吗？
5. 窄屏堆叠了吗？真实库干净吗？
