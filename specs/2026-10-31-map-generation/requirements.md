## 3. 决策

| 编号 | 决策                                                       | 理由                                                | 影响                                                |
| ---- | ---------------------------------------------------------- | --------------------------------------------------- | --------------------------------------------------- |
| D1   | 端到端一次做全                                             | 候选不落盘等于没解决问题；图是这一阶段的脸面        | 前后端同时改，PR 较大                               |
| D2   | 材料只支持**粘贴**                                         | 少一次 multipart 与编码处理；也逼使用者提供真实目录 | 大文件要用户自己分次贴                              |
| D3   | 候选**逐条可编辑**后再整批确认                             | mission「产物可校验」；模型拆错时用户能否决         | 前端多一屏确认态                                    |
| D4   | 图用 **`@xyflow/react`**                                   | tech-stack 已选；拖拽/缩放开箱即用                  | 新增运行时依赖，构建体积 +约 60KB gzip              |
| D5   | 按**小节数**切块，默认 8 节，`SDL_MAP_CHUNK_SECTIONS` 可调 | 比按字符切更不容易把一节劈成两半                    | 超长小节仍可能触发输入上限，按 `LLM_BAD_INPUT` 处理 |
| D6   | 落盘**只追加**；同名（忽略空白）自动加「（2）（3）」       | 绝不删用户已有节点；重生成不会毁掉手写内容          | 反复生成会产生重复语义的卡，需要人工收拾            |
| D7   | 覆盖检查**不阻止**落盘，只红字警告                         | 允许保存中间成果；「结构可校验」靠显示而不是拦死    | 库里可能出现未被路径覆盖的叶子                      |
| D8   | 真实冒烟在**临时库**                                       | 不污染真实运行库                                    | 冒烟结束后临时库丢弃                                |
| D9   | 生成前显示**预估 token 与费用**                            | 宽松预算下一次生成不便宜，用户应知情                | 单价走环境变量，默认值仅作量级参考                  |

### 3.1 接口契约（本期定稿）

```ts
// POST /api/goals/:goalId/map/preview   body: { material: string }
{
  candidates: { tempId: string; title: string; parentTempId?: string; why?: string }[]
  warnings: string[]          // 候选结构问题（悬空父/重名/空标题）
  estimate: { inputChars: number; inputTokens: number; outputTokens: number; costCny: number }
}

// POST /api/goals/:goalId/map/commit    body: { candidates: Candidate[] }
{ created: number; warnings: string[] }   // warnings = 四类覆盖检查的结果

// GET /api/goals/:goalId/map
{ nodes: { id: string; title: string; upId?: string; mastery: string }[]; warnings: string[] }
```

- 未配置 key：三个接口都返回 **503** `LLM_NOT_CONFIGURED`（preview）；commit/get 不需要 key。
- 上游错误沿用阶段 4 的映射（401/403 → 502 `LLM_AUTH`，429 → 429，超时 → 504，结构修复失败 → 422）。
- `commit` 不调用模型，只做确定性写入。

### 3.2 生成与合并规则

1. 材料按行切「小节」：去掉空行与纯装饰行，每 8 行一块；
2. 每块提示词要求：**只输出 JSON**，节点是「可验证概念」，每块 5–12 个，不得编造材料里没有的章节；
3. 单块 schema：`{ nodes: [{ temp_id, title, parent_temp_id?, why? }] }`；
4. 合并：按 `title` 去空白后去重（保留首次出现）；父引用只在块内有效，跨块悬空则降为顶层；
5. 结构警告：悬空父、重名、空标题；任一存在就随候选返回。

### 3.3 落盘规则

- 先建顶层，再按层建子节点；同一父下按候选顺序 → `order` 连续；
- 标题先 `sanitizeFileName`；与既有节点或本批重名时追加「（2）」；
- `goal` 必须存在且合法；不存在 → 404；
- 落盘后跑 `checkCoverage` + `checkDanglingResources`，把四类结果映射成中文警告。

## 5. 风险

| 风险                 | 缓解                                                            |
| -------------------- | --------------------------------------------------------------- |
| 大目录触发输入上限   | 按块发送；单块仍超限 → `LLM_BAD_INPUT` 且不发请求；提示用户拆小 |
| 模型编造章节         | 提示词约束 + 候选可删；不自动落盘                               |
| 合并后层级混乱       | 父引用跨块降级为顶层；结构警告显式列出                          |
| 反复生成产生重复节点 | 只追加 + 自动后缀；文档写明「重生成前先手动整理」               |
| React Flow 大图卡顿  | 本期 5–15 节点；超过 50 个只在图上折叠（后续阶段）              |
| 费用失控             | 预估 + 手动确认两次点击；重试有上限                             |
