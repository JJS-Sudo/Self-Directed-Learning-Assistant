## 3. 决策

| 编号 | 决策                                                      | 理由                                                          | 影响                                                                      |
| ---- | --------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------- |
| D1   | 空状态 = **定位句 + 主行动**，不造假数据                  | 阶段 3 才有数据；假数据会让评审误判「已经能用」               | 五区按钮禁用并标「阶段 N 开放」；目标区保留 health 卡片，让页面有真实内容 |
| D2   | SPA **接管 `/` 与 `/resources`**；无构建产物时旧 SSR 照旧 | 两个旧入口都属六区，漏一个导航就「漏」                        | `createApp` 的 `/resources` 分支加 `indexHtml` 判断；补一条服务端测试     |
| D3   | 默认落点 `/` = 目标                                       | 六环起点；空库时也最自然                                      | `/` 不再做重定向，直接渲染目标区                                          |
| D4   | 路由用 **React Router**（`BrowserRouter`）                | 生态成熟、嵌套与 404 现成；只多一个运行时依赖                 | 新增 `react-router-dom`；构建体积 +约 20KB gzip                           |
| D5   | **顶部横排**导航，窄屏横向滚动                            | 与现有 `max-width: 44rem` 单列版式一致，不改版式              | 导航要 `overflow-x: auto` + 不换行                                        |
| D6   | 未知路径：**前端 404 页 + HTTP 200**                      | 单机工具不需要 SEO 语义；服务端已能回落 index.html            | 不动 Hono 的 catch-all，只加 React 路由的 `*`                             |
| D7   | 样式拆 `tokens.css` + `base.css`，页面级样式随组件        | 阶段 3 起页面会变多，单文件会膨胀                             | `styles.css` 拆成两个文件并从 `main.tsx` 引入                             |
| D8   | **目标区保留阶段 1 的 health 卡片**                       | 让用户在空库里也能看到「系统是活的」，并保留阶段 1 的演示价值 | `HealthCard` 从 `App.tsx` 拆成组件，挂在目标区                            |

## 5. 风险

| 风险                                                       | 缓解                                                                      |
| ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 新增 `react-router-dom` 后 CI 的 `npm ci` 依赖 lock 不同步 | 提交前跑一次 `npm ls --depth=0`，并把 lock 一起提交                       |
| `/resources` 双份实现导致「dev 正常、prod 跳回旧页」       | 服务端测试注入 `webRoot` 断言 `/resources` 返回 SPA；手工再验一次生产构建 |
| 空状态五个禁用按钮看起来像坏掉                             | 每个按钮旁写明「阶段 N 开放」；目标区保留可交互的 health 卡片作对照       |
| 导航在 375px 下换行或溢出                                  | 固定 `flex-wrap: nowrap` + `overflow-x: auto`；验证时用 375px 视口截图    |
| 堆叠分支让 diff 包含阶段 1 的全部改动                      | 本阶段的 PR 以 `feat/phase-1-hello-hono` 为 base，diff 只显示阶段 2       |
