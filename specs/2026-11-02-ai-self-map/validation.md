## 2. 验收场景

### V1 · 默认自建（有 Tavily）

1. 选目标 → 点「AI 自动生成知识地图」；
2. 返回 ≥20 个候选 + 边；页面显示检索到的来源数；
3. 确认落盘 → `/map` 渲染出蛛网，边有类型；
4. 记录费用、耗时。

### V2 · 默认自建（无 Tavily）

1. 临时去掉 Tavily key 重启；
2. 同样生成成功；
3. 页面显示「本次未联网，仅用模型已有知识拆解」。

### V3 · 材料页

1. 地图页点「导入材料生成」→ `/map/material?goal=<id>`；
2. 粘贴目录 → 估算 → 生成候选 → 编辑 → 落盘；
3. 返回地图，节点数与候选一致。

### V4 · 边界

1. 模型返回 18 个节点 → 允许落盘，页面提示「建议 20 个以上」；
2. 模型返回一条指向不存在节点的边 → 丢弃并警告；
3. 材料页没选目标 → 提示回地图选目标。

## 3. 不通过的样子

- 默认模式仍要求粘材料，或按钮只是换了个位置。
- 无 Tavily 时直接报错，而不是降级。
- 20 个节点的图落盘后变回树（只有 parent，没有 sibling/related）。
- 一键生成后自动去检索资源（超出本期范围）。
- 材料页与默认页各自实现一套候选编辑，行为不一致。
- 真实库被冒烟写入。

## 4. 评审者 5 分钟检查单

1. 地图页第一屏就能一键生成吗？材料框没了吗？
2. 生成 ≥20 个点了吗？边有类型吗？
3. 没 Tavily 时还能生成且有提示吗？
4. 材料页能往返吗？落盘后地图更新了吗？
5. 费用说明在吗？真实库干净吗？
