## 3. 决策

| #   | 决策                                                                       | 理由                  |
| --- | -------------------------------------------------------------------------- | --------------------- |
| D1  | 默认模式**不需要用户再输入**，只读目标标题与成功判据                       | 一键即得              |
| D2  | Tavily 检索：用「目标标题」与「成功判据」各查一次，取 top 5 摘要拼成上下文 | 覆盖面与费用平衡      |
| D3  | 检索或模型调用失败时**不整体失败**：检索失败降级为纯模型；模型失败才报错   | 没有 key 的用户也能用 |
| D4  | 一次调用输出 20–30 节点 + 边；不分块（目标文本短）                         | 结构连贯，费用可控    |
| D5  | 材料模式保留现有分块逻辑，只移动到子页                                     | 不破坏已有能力        |
| D6  | 生成结果先返回候选（可编辑），确认后才写盘                                 | 与现在一致            |
| D7  | 检索摘要只在内存里用作提示词，不写库、不回显全文                           | 隐私与体积            |
| D8  | 无 Tavily 时的提示文案：「本次未联网，仅用模型已有知识拆解」               | 让用户知道差异        |

### API 契约

```ts
// POST /api/goals/:id/map/ai   （新，默认模式；不落盘）
{
  candidates: { tempId, title, parentTempId?, why? }[],
  edges: { from, to, type: 'parent'|'sibling'|'related' }[],
  warnings: string[],
  research: { used: boolean, sources?: { title: string, url: string }[] },
  estimate: { inputTokens, outputTokens, costCny, calls }
}

// 材料页继续用：
// POST /api/goals/:id/map/estimate
// POST /api/goals/:id/map/preview
// POST /api/goals/:id/map/commit
```

- `research.used=false` 时，`warnings` 必含「未联网」说明；
- 边引用不存在的候选 → 服务端丢弃并加 warning；
- 节点标题去重、parent 唯一沿用现有 merge 逻辑。

### 提示词要点（AI 自建）

- 角色：学习设计师；围绕目标与成功判据，拆出 **20–30 个可验证知识点**；
- 允许利用联网摘要；摘要不足时用通用知识，不得编造具体页码/数据；
- 输出层级（parent 唯一）+ 少量 sibling / related；
- 顶层节点挂到目标下，不发明虚拟根；
- 只输出 JSON：`{"nodes":[...],"edges":[...]}`。

## 5. 风险

| 风险                                 | 缓解                                                                 |
| ------------------------------------ | -------------------------------------------------------------------- |
| 模型一次输出 20–30 节点容易超长/截断 | schema 上限 40，`max_tokens` 足够；截断时给 warning 并保留已解析部分 |
| 20+ 节点图太密                       | 力导向与单色卡片已就绪；可后续加「只看某分支」                       |
| Tavily 配额被一次生成吃掉            | 只查 2 次、top 5；无 key 不调用                                      |
| 材料页与默认页代码重复               | 抽公共候选编辑组件，页面只负责输入与提交                             |
| 用户不知道默认模式花不花钱           | 按钮旁写明「约 ¥0.0x / 次，联网时另含检索」                          |
